# Snake Classic — SoloHost install kit

Use the two install files:
- docker-compose.yml
- config_options.yml

Suggested name: Snake Classic
Suggested description: Create a simple mobile Snake game.  - Classic snake gameplay: move, eat food, grow longer. - Swipe controls and optional on-screen arrows. - Collision with walls or the snake ends the game. - Score and high score. - Start, Pause, Restart buttons. - Increasing speed as the snake grows. - Clean, color
